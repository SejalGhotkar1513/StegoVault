# StegoVault — Image Steganography

A Streamlit web application for hiding and extracting text messages inside images using LSB steganography.

## Features
- Encode a UTF-8 text message into an image
- Decode a hidden message
- PNG download
- Modern responsive interface
- No database or API keys required

## Run locally

```bash
pip install -r requirements.txt
streamlit run app.py
```

## Streamlit Cloud

Upload this folder to a GitHub repository and deploy `app.py` as the main file.
